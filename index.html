Qual é o CEP dessa cidade?

Digite a cidade e veja o CEP direto da base dos Correios (via ViaCEP). Cidades grandes têm um CEP por rua — informe a rua para achar o exato.

A lista de cidades vem do IBGE. Sem rua, o site lista os CEPs de logradouros encontrados na cidade.

Fontes: ViaCEP (base dos Correios) e API de localidades do IBGE. Para confirmação oficial, use a Busca CEP dos Correios.
